Παλέτα **χρυσό / λευκό / μαύρο / απαλό ροζ**, με το χρυσό δειγματοληπτημένο από
το λογότυπο (`#b4783c`).

## Προσφορές — πώς τις αλλάζετε

> **Οι 4 προσφορές που είναι live τώρα είναι ΕΝΔΕΙΚΤΙΚΕΣ** — γραμμένες από εμάς
> ως προτάσεις, **χωρίς τιμές** (εμφανίζουν «τηλεφωνήστε μας για την τιμή»).
> Αντικαταστήστε τες με τις πραγματικές μόλις τις δώσει η κ. Σπυριδάκη.
>
> Αν αδειάσετε τη λίστα (`OFFERS = []`), η ενότητα εξαφανίζεται από παντού:
> αρχική, μενού, footer, sitemap — και δεν παράγεται καν το `prosfores.html`.

Ζουν στο `OFFERS` στην κορυφή του `build/data.mjs`. Εμφανίζονται σε δύο σημεία:
κάρτες στην **αρχική** (ενότητα «Οι προσφορές μας») και αναλυτικά στο
**`prosfores.html`**. Το «Μάθετε περισσότερα» της κάρτας πάει στο αντίστοιχο
σημείο της σελίδας προσφορών.

Για κάθε προσφορά:

| Πεδίο | Τι κάνει |
|---|---|
| `neo: true` | εμφανίζει την ένδειξη **ΝΕΟ**. Γράψτε `false` όταν πάψει να είναι νέα |
| `title` | ο τίτλος |
| `lead` | οι 1–2 γραμμές στην κάρτα |
| `body` | οι παράγραφοι στη σελίδα προσφορών |
| `includes` | η λίστα «Τι περιλαμβάνει» |
| `price` | π.χ. `"από 180€"` ή `"-20%"`. **Κενό = δεν δείχνει τιμή**, μόνο «τηλεφωνήστε μας» |
| `validity` | προαιρετικό, π.χ. `"Ισχύει έως 30/9"` |
| `slug` | το αναγνωριστικό στο URL — λατινικά, χωρίς κενά |

Η **ένδειξη ΝΕΟ δεν σβήνει μόνη της** — μπαίνει και βγαίνει χειροκίνητα.
Νέα προσφορά: αντιγράφετε ένα μπλοκ, αλλάζετε τα πεδία. Απόσυρση: σβήνετε το
μπλοκ. Μετά από κάθε αλλαγή τρέχετε `node build/build.mjs`.

#### Σημειώσεις για συντήρηση μέσω API

Τα credentials **μπαίνουν και μέσω του public API** — δεν απαιτείται το UI, όπως
νομίζαμε αρχικά:

```
PUT /api/v1/workflows/:id
{ "name":…, "nodes":…, "connections":…, "settings":… }
```

με `credentials: { "googleCalendarOAuth2Api": { "id": "…", "name": "…" } }` πάνω στο
node. Δύο παγίδες:

- Το `settings` πρέπει να σταλεί **φιλτραρισμένο**. Το API δέχεται μόνο
  `executionOrder`, `timezone`, `errorWorkflow`, `saveData*`, `executionTimeout`·
  οτιδήποτε άλλο (π.χ. `availableInMCP`, `binaryMode`) το κόβει με
  `400 request/body/settings must NOT have additional properties`.
- Το PUT θέλει ολόκληρο το workflow, όχι patch.

Οι υπενθυμίσεις φεύγουν με **email** μέσω του Gmail της Έλενας, χωρίς κόστος και
χωρίς πάροχο SMS. Πάνε μόνο σε ραντεβού που έχουν διεύθυνση email στην περιγραφή.
